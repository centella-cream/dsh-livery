# Support

- **Bug reports and feature requests:** use the GitHub issue templates.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not open a public issue.
- **Questions and usage help:** open a discussion or an issue with the `question`
  label. Include your host build (`dsh --version`), profile (Web or Desktop), OS and
  plugin version.
- **Documentation:** start at [docs/README.md](docs/README.md) and
  [docs/verification.md](docs/verification.md).

This is a community project maintained on a best-effort basis. There is no
commercial support commitment.

## Uninstall

Removing the plugin with the DSH plugin manager leaves the plugin's `livery`
configuration row in the profile. Reinstalling may restore the previous style.
Use **Restore default appearance** before uninstalling, or delete the `livery`
row from the profile configuration, if you want a clean start.
